# Obsy Launcher

_(🇷🇺 Русская версия ниже)_

Obsy Launcher is a modern, cross-platform Minecraft launcher built using web technologies and Rust.

It is built with **Tauri**, **React**, **Vite**, and **Tailwind CSS**.

## Features

- Fast and lightweight
- Modern UI built with React and Tailwind CSS
- Secure backend powered by Rust

## 🚀 Getting Started

### 📥 Download & Install (For Users)

1. Go to the [Releases](https://github.com/obsy-official/obsy-launcher/releases) page.
2. Download the latest version for your operating system:
   - **Windows:** `.exe` or `.msi`
   - **macOS:** `.dmg` or `.app`
   - **Linux:** `.deb` or `.AppImage`
3. Run the installer and play!

---

### 💻 Development (For Developers)

#### Prerequisites

Ensure you have the following installed on your system:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Rust](https://www.rust-lang.org/tools/install)
- [Tauri Prerequisites](https://tauri.app/v1/guides/getting-started/prerequisites) (depends on your OS)

### Installation & Development

```bash
git clone https://github.com/obsy-official/obsy-launcher.git
cd obsy-launcher
npm install
npm run tauri dev
```

### 💻 Разработка (Для разработчиков)

#### Требования

Убедитесь, что у вас установлены:

- [Node.js](https://nodejs.org/) (версия 18 или выше)
- [Rust](https://www.rust-lang.org/tools/install)
- [Зависимости Tauri](https://tauri.app/v1/guides/getting-started/prerequisites) (в зависимости от вашей ОС)

### Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/obsy-official/obsy-launcher.git
   cd obsy-launcher
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите в режиме разработки:
   ```bash
   npm run tauri dev
   ```

### Сборка

Чтобы собрать готовый `.exe`, `.app` или `.deb` файл для вашей системы:

```bash
npm run tauri build
```
